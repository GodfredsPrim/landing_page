# Archivo

Archivo variable font by Omnibus-Type, distributed under the SIL Open Font License in `OFL.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/archivo

`archivo-latin.woff2` is a WOFF2 subset made with FontTools from `Archivo[wdth,wght].ttf`. It retains Latin, punctuation and the open-e character used in the Ghanaian hackathon name. No glyph designs were changed. It is served locally with `font-display: swap` and a system fallback.
